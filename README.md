# Guali Tutor Móvil

Tutorial para crear el *front end* Android de **Guali Tutor** (Fase 3 del proyecto de Programación II, Universidad Mariano Gálvez de Guatemala).

## Tutorial

**[Abrir el tutorial → TUTORIAL.md](TUTORIAL.md)**

Explica, con capturas de pantalla, cómo instalar Android Studio y construir en Java la interfaz principal de la aplicación: barra de menú, título de lección activa, panel de lección, editor de código, botones Compilar/Ejecutar y consola.

## Contenido del repositorio

| Ruta | Descripción |
|---|---|
| `TUTORIAL.md` | Tutorial paso a paso |
| `codigo-fuente/app/src/main/` | Código y recursos que se crean en el tutorial (`MainActivity.java`, layouts, menú, textos, colores) |
| `docs/img/` | Capturas de pantalla del tutorial |
